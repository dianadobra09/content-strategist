# Repurpose

Paths are relative to the workspace root. Use the shared rules in `CLAUDE.md`.

## A. Adapt to another platform

Read the source and the requested platform skill. Preserve the strongest useful point, its qualifications and its feeling (`references/psychology.md`).
LinkedIn allows fuller context; X favors one point or useful ordered steps; Bluesky follows its focus in positioning; Threads favors one short point in the author's words. X, Threads and Bluesky get no first reply.
Adapt only for requested platforms. Respect platform fit, and flag a mismatch unless the author explicitly requests an exception.
Do not force different wording when the author's sentence already works. Change context, length and visual crop where needed.
Use the channel's limits and `strategy/visuals.md`. Run `humanizer`, then `voice-check`, once per version.
Save versions in the same post file.

## B. Extract from a long source

Read the source and identify distinct useful points with their supporting material.
Apply `generate-content` steps 3–4. Separate the author's statements from external findings and missing input.
Show a short list of strong candidates with purpose and evidence. Do not stretch one insight into several thin posts.
Let the author choose unless they delegated selection. Save unchosen useful angles without duplicates.
Draft each selected point with the relevant channel skill.

## C. Develop a follow-up

Read the earlier post and the new material. Identify the new result, failure, changed decision or useful question it answers.
No minimum age or successful original post is required. A new opener alone is insufficient.
For a measured result, record the starting conditions, change, observation period, output and limitation.
If evidence is missing, save a collection brief rather than claim an outcome.
Create a separate post file and link the original in its brief. Preserve the original and its approval status.
Rank the follow-up by reader value and evidence, just like a new topic.
