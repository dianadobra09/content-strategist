# Published

One row per published post. Ready drafts do not count as results.
`content-plan` records the first ten posts per platform as a descriptive baseline.

| Date | Platform | Post file | Pillar | Category | Purpose | Format | Hook | Reach | Visual | Evidence | Link | 48h | 7d | Useful outcomes |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|

For each 48h or 7d entry, record the actual observation time or age, impressions, reactions, reposts and available comment counts. On X and Threads also record follows and profile visits, on Threads the views from non-followers, and whether the post is a question or a statement.
Separate outside commenters from the author's replies when possible. Record missing metrics as unknown, not zero.
Useful outcomes can include specific technical questions, continuing conversations, resource use or attributed follows.
Add saves, profile visits, clicks and signups only when analytics supplies them. Note how an outcome was attributed.
Link longer outcome notes from the post file rather than crowding this log. Never invent data to complete a row.
